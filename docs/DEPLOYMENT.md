# Deployment guide (Ubuntu, Gunicorn, systemd, HTTPS)

This guide deploys FreshCircle to `/opt/groupbuy` on Ubuntu 22.04 or 24.04, using PostgreSQL, Gunicorn and systemd. It does **not** assume Nginx is installed. Choose a reverse proxy in step 6.

## 1. Server user and code

```bash
sudo adduser --system --group --home /opt/groupbuy groupbuy
sudo git clone <your-repo-url> /opt/groupbuy
sudo chown -R groupbuy:groupbuy /opt/groupbuy
cd /opt/groupbuy
```

## 2. Install (packages, venv, PostgreSQL, .env, migrations)

```bash
sudo -u groupbuy -H bash -c 'cd /opt/groupbuy && ./scripts/install_ubuntu.sh --no-apt --postgres' \
  || sudo ./scripts/install_ubuntu.sh --postgres   # first run needs sudo for apt/PostgreSQL
sudo chown -R groupbuy:groupbuy /opt/groupbuy
```

Then edit `/opt/groupbuy/.env` (`chmod 600`, owned by `groupbuy`):

```
FLASK_ENV=production
SECRET_KEY=<64 hex chars, generated by the installer>
DATABASE_URL=postgresql://groupbuy:<generated>@localhost:5432/groupbuy
BEHIND_PROXY=1
SESSION_COOKIE_SECURE=1
CONTACT_EMAIL=support@yourdomain.com
```

In production the app refuses to start if `SECRET_KEY` or `DATABASE_URL` is missing.

## 3. Initial accounts

```bash
cd /opt/groupbuy && sudo -u groupbuy .venv/bin/flask --app wsgi.py create-admin --email you@yourdomain.com
sudo -u groupbuy .venv/bin/flask --app wsgi.py create-founder-vendor --email founder@yourdomain.com \
     --business-name "Your Produce Co" --phone "+91 ..." --address "..." --capacity 1000
```

Do not run `seed-demo` in production.

## 4. Gunicorn under systemd

```bash
sudo cp deploy/groupbuy.service deploy/groupbuy-deadlines.service deploy/groupbuy-deadlines.timer /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now groupbuy
sudo systemctl enable --now groupbuy-deadlines.timer
sudo systemctl status groupbuy
curl -I http://127.0.0.1:8000/
```

* Logs: `journalctl -u groupbuy -f`.
* Tune workers with `GUNICORN_WORKERS` / `GUNICORN_THREADS` in `.env`.
* The deadline timer runs `flask process-deadlines` every minute. It freezes orders at their deadline, closes bidding and applies auto-score awards.

## 5. Updating

```bash
cd /opt/groupbuy
sudo -u groupbuy ./scripts/backup.sh
sudo -u groupbuy git pull
sudo -u groupbuy .venv/bin/pip install -r requirements.txt
sudo -u groupbuy .venv/bin/flask --app wsgi.py db upgrade
sudo systemctl restart groupbuy
```

## 6. Domain and HTTPS (choose one reverse proxy)

First point your domain's DNS **A/AAAA records** at the server, then open ports 80 and 443:

```bash
sudo ufw allow OpenSSH && sudo ufw allow 80,443/tcp && sudo ufw enable
```

### Option A — Caddy (simplest; automatic certificates)

```bash
sudo apt install -y caddy
sudo cp deploy/Caddyfile.example /etc/caddy/Caddyfile   # replace example.com with your domain
sudo systemctl reload caddy
```

### Option B — Nginx + Let's Encrypt

```bash
sudo apt install -y nginx certbot python3-certbot-nginx
sudo cp deploy/nginx.conf.example /etc/nginx/sites-available/groupbuy   # edit server_name
sudo ln -s /etc/nginx/sites-available/groupbuy /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx
sudo certbot --nginx -d yourdomain.com -d www.yourdomain.com          # adds TLS + HTTP→HTTPS redirect
```

The Nginx example also applies per-IP rate limits to the login and registration endpoints. This works across all Gunicorn workers.

Either way, Gunicorn stays bound to `127.0.0.1:8000` and is never exposed directly. Keep `BEHIND_PROXY=1` so the app sees the real client IP and the HTTPS scheme.

## 7. Backups

```bash
sudo -u groupbuy /opt/groupbuy/scripts/backup.sh /opt/groupbuy/backups
```

Schedule it daily with cron for the `groupbuy` user:

```
15 2 * * * cd /opt/groupbuy && ./scripts/backup.sh /opt/groupbuy/backups >> /opt/groupbuy/backups/backup.log 2>&1
```

* Copy backups **off the server** (for example `rclone` or `rsync` to object storage).
* Retention defaults to 14 days (`BACKUP_RETENTION_DAYS`).
* Test restores regularly.

To restore:

```bash
sudo systemctl stop groupbuy
sudo -u groupbuy /opt/groupbuy/scripts/restore.sh backups/db-YYYYmmdd-HHMMSS.dump backups/uploads-YYYYmmdd-HHMMSS.tar.gz
sudo -u groupbuy /opt/groupbuy/.venv/bin/flask --app wsgi.py db upgrade
sudo systemctl start groupbuy
```

`restore.sh` asks you to confirm and takes a safety backup to `backups/pre-restore/` before it replaces anything.

## 8. Operational checklist

- [ ] `.env` is `chmod 600`, owned by `groupbuy`, and not in git.
- [ ] HTTPS works, and `SESSION_COOKIE_SECURE=1`.
- [ ] `systemctl list-timers | grep groupbuy` shows the deadline timer.
- [ ] Daily backups are copied off the server, and a test restore has been done.
- [ ] The Privacy Policy and Terms have been reviewed for your jurisdiction.
- [ ] Payment instructions (Admin → Settings) are filled in with your real, non-secret payment details.
